# Roadmap de Funcionalidades Futuras

Este archivo registra las ideas y características que decidimos posponer para fases futuras, evitando perder el hilo del desarrollo y previniendo alucinaciones sobre el estado actual del sistema.

## Características Postergaras

### 🚀 MMM Todo Lo Que Quiero Comer

*   **Integración de Reseñas con Google Reviews (API)**
    *   *Descripción*: Sincronizar el sistema interno de valoraciones de la aplicación con Google My Business. Al finalizar un pedido exitoso, incentivar al comensal a publicar la reseña directamente en Google de forma automatizada para rankear mejor en búsquedas locales.
    *   *Motivo de postergación*: El sistema actual cuenta con valoraciones internas pero aún no está completada al 100% la integración externa con la API de Google Reviews. Se removerá del embudo de ventas actual y se agregará más adelante.
